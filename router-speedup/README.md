# Router speedup

A guided check of your home Wi-Fi with Claude Code. Claude measures speed and ping, reads your router's
Wi-Fi pages with you, suggests safer channels and DNS settings, and measures again so you see whether it helped.

In one home this cut average ping by about 40% and made downloads steadier, just by moving off a busy
radar (DFS) channel.

- Claude never changes router settings or types passwords: you click, Claude guides.
- Needs: Claude Code with a browser tool (Claude in Chrome or the built-in browser), and the router's login.

Start: tell Claude "run the router speedup check". Claude follows [GUIDE.md](GUIDE.md).
